docs/literate/concise-hello.org: a 36-line typed decision model, annotated block by block, tangling demos/typed-decisions/concise-hello.mlpl and its corpus (demos/typed-decisions/messages.json) byte for byte. Inference is five lines; the other eleven substantive lines are the training loop and loss, which the Python comparison does not have because it borrows a pretrained model. Corpus passed in on the command line and parsed with parse_json in one line, so the program carries no data -- deliberately not browser-safe, since that means read_text and args. Model DSL linear() for the three heads. Gate: check-typed-decisions runs it and pins its answer; check-tangle now accepts a document whose tangled source has its own gate check.
